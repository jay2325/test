## Real Estate Lead Qualification + Speed-to-Lead Automation (MVP v1)

The Next.js app lives in `lead-automation/`.

### Quickstart

```bash
cd lead-automation
cp .env.example .env
npm install
npx prisma migrate dev
npm run dev
```

### Notes

- `javier_portfolio/` is legacy content from before this MVP scaffold.
- This repo is being built incrementally to match the full spec (Twilio, OpenAI scoring, job runner, CRM sync, UI).
